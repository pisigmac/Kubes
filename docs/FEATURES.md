# Kubes Feature Catalog & Capabilities

## Core Features

1. **Autonomous Specialist Pods (Cubes)**:
   - Configurable personas, instructions, and target pain points.
   - Dynamic model assignment per specialist (GPT-4o, Claude 3.7 Sonnet, Gemini 2.0 Flash, DeepSeek-R1, Llama 3.3).
2. **Interactive Visual Artifact Studios & Live Canvas**:
   - **Mermaid Studio**: Interactive pan/zoom canvas, orientation toggle (`TD` ⬌ `LR`), syntax error resilience, and 1-click SVG / high-DPI PNG export.
   - **CSV Grid Studio**: Sortable tabular ledger with type-ahead search filter, column totals (`Σ Sum`, `Avg`), dynamic SVG bar distribution charts, and CSV export.
   - **Sandboxed Preview Runner**: Secure HTML/component preview runner with isolated `sandbox="allow-scripts"` iframe, multi-device viewports (100%, Desktop, Tablet, Mobile), and an expandable console message inspector.
   - **Markdown Document Viewer**: Rich formatting for specialist briefings, action item checklists, and reports.
3. **Multi-Agent Swarm Collaboration DAG**:
   - Hierarchical objective decomposition into parallel and sequential topological stages.
   - Real-time visual DAG execution graph with duration timers and task inspection modals.
   - Maestro executive synthesis node compiling deliverables and checklists.
4. **Autonomous Task Scheduling Engine**:
   - Standard 5-field cron parsing with minimum 5-minute safety threshold.
   - Execution state tracking (`ok`, `error`, `running`).
5. **Executive Digest Notification System**:
   - Structured outcomes, desktop notifications (`notify-send`, AppleScript, PowerShell), Slack/Discord webhooks, and daily markdown logs.
6. **Computer Tooling & Sandboxed Execution**:
   - Exclusive lock seat execution, Linux Bubblewrap jail isolation, out-of-band egress credential proxy, and headless Chromium automation.
